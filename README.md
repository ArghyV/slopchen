# Slopchen

A digital implementation of **Austrian Schnapsen** (a 2-player, 20-card trick-taking
game), consisting of a TypeScript game engine, a simple rule-based "weak" AI
opponent, and a React/Vite PWA front end.

> **⚠️ This project is entirely LLM-coded.**
> The engine, the AI, the UI, and the tests were all generated by an AI
> assistant, and no human has verified that the implementation matches the
> real rules of Schnapsen or is otherwise correct. Treat everything in this
> repo as an unreviewed first draft: it *runs*, it *looks* plausible, and
> parts of it are simply wrong — including some rules baked into both the
> code and the tests (i.e. the tests won't save you). See
> [`TODO.md`](./TODO.md) for the specific issues found so far. If you're
> picking this up, assume there are more that haven't been found yet.

## What's here

```
src/engine/     Core game rules: cards, deck, dealing, turns, scoring
src/ai/         weak.ts — a simple heuristic AI opponent (no search/lookahead)
ui/             React + Vite PWA — play against the weak AI in the browser
```

There is currently **no "strong" AI** (no search, no card-probability
tracking, no perfect-information endgame solver) — only the rule-based weak
player exists, despite that being a stated goal at some point.

## Requirements

- Node.js (any reasonably recent LTS)
- npm

## Setup

```bash
# Engine + AI + tests (repo root)
npm install

# UI (separate package)
cd ui && npm install
```

## Running

**Play in the browser:**
```bash
cd ui
npm run dev
```
Opens a local dev server; you play as `p0` against the `weak` AI as `p1`.

**Run the engine test suite:**
```bash
npm test
# or
npm run test:watch
```

**Build:**
```bash
npm run build       # compiles the engine (tsc)
cd ui && npm run build   # builds the PWA (tsc + vite build)
```

## Known state of correctness

The engine test suite passes, but several tests were written to match
behavior that doesn't match the actual rules of Schnapsen — so "tests green"
does not currently mean "rules correct." Known problems include incorrect
talon-closing rules, a missing "closer fails to reach 66" penalty, no
Schneider/Schwarz game-point scoring, a trick-resolution bug where the wrong
player draws from the talon, a trump-exchange implementation that can read
the opponent's hidden hand, and a UI that renders the opponent's hand face-up
and deals identical cards every game. Full details are in
[`TODO.md`](./TODO.md).
